What is Stream Fusion?

Lightweight UI building blocks with Tailwind.

Why this guide?

Set up, integrate, and ship features faster—without the mess.

Get Started

  1. Use Tailwind via CDN for quick prototypes.
  2. Drop in this layout scaffold (header, sidebar, shell).
  3. Toggle dark mode using localStorage.

Tip: Compose layouts with small, reusable parts.
